# Кутман Омуралиев — Бизнес-аналитик | Сайт-визитка

Продающий лендинг-визитка бизнес-аналитика **Омуралиева Кутмана**.
Сайт строит путь клиента по формуле: **проблема → решение → примеры → доверие → действие**.

🔗 **[kutya001.github.io/My-Services](https://kutya001.github.io/My-Services/)** · резюме: [kutya001.github.io/KutEmpResume](https://kutya001.github.io/KutEmpResume/)

---

## Стек

| Технология | Назначение |
|---|---|
| React 19 + Vite 5 | SPA и сборка |
| Tailwind CSS 3 | Стили, три темы |
| Font Awesome 6 (npm, без CDN) | Иконки |

| Google Apps Script | Приём заявок и статистика визитов |

## Возможности

- **Фон «хаос → система»** — частицы на первом экране летают хаотично, а при прокрутке выстраиваются в ровную сетку.
- **Блоки выплывают при прокрутке** — у каждого раздела своё появление (сдвиг, размытие, «переворот», разлёт карточек).
- **«На выходе — конкретные артефакты»** — схема-конвейер: шаги появляются по очереди, по стрелкам бегут «пакеты данных».
- **Кейсы** — мини-схема задача → решение → что даёт, плюс **интерактивный демо-дашборд** (филиал, показатель, таблица) на вымышленных данных; столбцы «вырастают» при появлении.
- **«Почему мне доверяют»** — схема-звезда: в центре фото, лучи прорисовываются к причинам; наведение подсвечивает луч и показывает причину в центре.
- **Тест «Насколько бизнес управляется цифрами»** — 5 вопросов, результат с рекомендацией; кнопка переносит результат в форму заявки или в WhatsApp.
- **Понятный путь (10 этапов)** — липкая шкала сверху показывает фазу и «Этап N из 10», линия маршрута заливается цветом этапов, бегущая точка показывает, где вы; у пройденного этапа появляется галочка и строка «На выходе». Клик по точке шкалы переносит к этапу.
- **Отзывы** — блок появляется, когда в данных есть реальные отзывы (`testimonials.items`).
- **Быстрый контакт** — WhatsApp с готовым текстом, плавающая кнопка на телефоне, «Сохранить контакт» (vCard) и QR-код со ссылкой `?src=qr`.
- **Верхняя панель как в резюме**: три темы (Белый / Тёмный / Тёплый) с плавной сменой и переключатель языков RU / KG / EN; ссылка `?lang=en` открывает нужный язык.
- **Карточки** с наклоном и световым пятном под курсором; всё движение отключается при системной настройке «Уменьшить движение».
- Превью ссылки для мессенджеров (OG), иконка сайта, структурированные данные schema.org.

## Как обновлять

| Что | Где |
|---|---|
| Опыт работы и навыки | Правьте `src/shared/career.json` в репозитории **KutEmpResume** — визитка подтягивает его с сайта резюме автоматически. Локальная копия здесь нужна на случай, если сайт резюме недоступен. |
| Тексты, кейсы, тест, цены, FAQ | `src/data-service.json` (RU), `-kg.json`, `-en.json` |
| Отзывы | `testimonials.items`: `{ "text": "...", "name": "...", "role": "...", "photo": "" }` |
| LinkedIn | `PERSON.linkedin` в `src/shared/site.js` |
| Анонимная статистика (GoatCounter) | `GOATCOUNTER_CODE` в `src/shared/analytics.js` |

Папка `src/shared` одинаковая в обоих репозиториях.

Статистика визитов больше не собирает IP и геолокацию; источник перехода виден по метке `?src=…` или `utm_source`.

## Структура проекта

```
├── index.html                  # Точка входа, мета-теги и превью ссылки
├── public/                     # Фото, логотипы, favicon, og-image
└── src/
    ├── App.jsx                 # Страница и секции
    ├── tracking.js             # Заявки и статистика (Google Apps Script)
    ├── style.css               # Tailwind + анимации блоков визитки
    ├── data-service*.json      # Контент на трёх языках
    ├── shared/                 # Общее с резюме: career.json, панель, темы, анимации появления
    └── components/             # Артефакты, кейсы, дашборд, «Почему мне доверяют», этапы, тест, визитка-QR
```

## Запуск

```bash
npm install
npm run dev       # разработка
npm run build     # сборка в dist/
npm run preview   # предпросмотр сборки
```

Деплой — GitHub Actions на GitHub Pages при пуше в `main` (`base: '/My-Services/'` в `vite.config.js`).
